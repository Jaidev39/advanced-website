# Jaidev Chowdary Portfolio Website

An early personal portfolio website built as a static front-end project.

## Overview

The site presents my profile, projects, tools, services, and contact information through a responsive single-page layout with navigation and animated visual elements.

## Tech stack

- HTML
- CSS
- JavaScript
- Bootstrap
- jQuery
- Font Awesome
- Parallax and animation libraries

## Status

This is an earlier-generation portfolio and is preserved as part of my development history. My current admissions-focused portfolio is maintained in the Jaidev39 repository.

## Run locally

Open index.html in a browser or serve the directory with any simple static web server.
